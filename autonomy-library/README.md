# Autonomous Life — Offline Library (RU)

> Кризисная библиотека: вода, питание, энергия, первая помощь, безопасность, гигиена, связь и семейный план.

## Назначение

Это **публичный шаблон каталога**, а не хранилище персональных сведений. Основные рабочие Google Docs и PDF лежат в закрытом Google Drive. В GitHub — переносимый каталог, структура и офлайн-интерфейс без зависимостей.

## Как использовать

1. Сохраните `index.html` локально и откройте его в современном браузере (он работает без интернета).
2. Для полного офлайн-архива храните PDF рядом в отдельной папке `pdf/` и проверяйте их открытие в авиарежиме.
3. Скопируйте каталог и документы также на запасной телефон или носитель.
4. Не рассчитывайте на облачные ссылки, когда нет связи.

## Safety-first

- При подозрении на химическое загрязнение воды кипячения недостаточно.
- Генераторы, мангалы и походные горелки не должны использоваться в помещении или у входов/вентиляции.
- Первая помощь — ознакомительный материал, не замена очному обучению.
- Персональные телефоны, адреса, документы и маршруты не публиковать в репозитории.
