# Play Caribbean Merchant v1.0

**[Download the single-file game](CaribbeanMerchant_v1.0.html)** · [Project overview](../README.md)

1. Open the file's GitHub page and use **Download raw file**.
2. Save as **`CaribbeanMerchant_v1.0.html`** (English filename).
3. Open the file in a modern desktop browser (Chrome / Edge). No server, installation, login or internet is required.
4. Switch language **RU / EN / AZ** from the header.
5. In the game choose **How to play** for instructions and **Export save** to create a JSON backup.

Your browser stores progress locally. Before opening a newer HTML build, export the old save as JSON and re-import it into the new build. Browser storage may treat local file versions separately.

**Notes:** The v1.0 QA tested the embedded game in Chromium but could not verify the actual double-click flow on your Windows machine due to sandbox navigation restrictions. If security/privacy software blocks local files, first verify using a standard browser download; don't disable corporate controls.
