# Attribution, ownership and distribution

**Caribbean Merchant** is an independent personal project inspired by memories of a commercially published naval trading game.

- **Port Royale / Port Royale 2** names and original commercial game assets belong to their respective owners. This project is not endorsed by the original publisher/developer.
- The game's HTML, CSS and JavaScript were independently produced using AI-assisted coding and owner-directed design/testing. No source archive, original images, music, levels or JAR from Port Royale were included.
- The physical Caribbean map uses cropped/shaded geography from Basemap relief rasters, including `etopo1.jpg` and `shadedrelief.jpg`, processed into embedded imagery. See [NOAA global relief model](https://www.ncei.noaa.gov/products/etopo-global-relief-model) and [Basemap documentation](https://matplotlib.org/basemap/stable/).
- The user-provided Dreamstime and Dergachev maps served as visual references only; they were not copied into the distributed HTML.
- **No license has been declared for original project code.** This is a public showcase and playable download; viewing the source does not by itself grant redistribution or commercial-use rights. An explicit LICENSE may be added later by the owner.
