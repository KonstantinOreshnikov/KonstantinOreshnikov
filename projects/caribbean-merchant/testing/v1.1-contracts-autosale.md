# Caribbean Merchant v1.1 — regression evidence

**Branch:** `fix/caribbean-contracts-bulk-autosale-20261119`  
**Playable artifact:** `play/CaribbeanMerchant_v1.1.html`  
**Source:** `src/game.js` (same embedded JS in the standalone HTML)  
**Source input for compatibility test:** player's `caribbean_merchant_day_1238.json`, day 1238, rank index 3.

## Defects reproduced from save

- At day 1238, 14 of 15 available governor offers had expired deadlines. One New Orleans offer remained valid.
- Daily simulation used to regenerate only null jobs, never expired offers. Accepted overdue offers could then be removed on travel simulation before arrival.
- Career contract counter was zero and blocked the respected merchant title despite extensive other achievements.
- The one-click delivery button already existed, but it was not reachable for a contract removed or expired en route.
- Palace and capital were both gated on zero-based rank index >=10 (11th title: Port Governor); existing city UI did not adequately explain the sequence.

## Repairs

- Existing stale job offers rotate immediately at import/render and refresh every 7 game days; accepted jobs are not recycled until the next simulated day.
- Some new offers are priority orders with +50% gross reward and +8 instead of +5 reputation. Normal orders retain +5.
- Accepted contract cargo is loaded atomically from ship, private stock and market; arrivals with sufficient cargo display an immediate one-click completion action.
- Successful delivery consumes contract cargo and credits gold, reputation, career contract counter and local nation standing. Ordinary trade sales remain separate.
- Global auto-sale buttons 0%, 75%, 100% adjust all production sites across all ports in one operation. Reserve/minPrice remain untouched; newly created factories inherit the policy.
- Palace and capital gating explained in RU, EN and AZ; original rank requirement remains unchanged.

## QA carried out

- **PASS**: JavaScript syntax compile and exact identity between modular source and standalone embedded script.
- **PASS**: 19 synthetic-DOM gameplay assertions, covering stale-offer rollover, acceptance, loaded cargo, arrival CTA, delivery, reward and career accounting, bulk auto-sale and palace rank gate.
- **PASS**: 14 assertions using the actual uploaded day-1238 JSON in a synthetic DOM runtime: 14 expired offers regenerated, first new Maracaibo contract (coffee x20 to Veracruz) accepted and fulfilled, career counter 0→1, rank 3→7 as other gates were already met, and 132 existing industries switched to both 100% and 75% without mutating reserve/minPrice.
- **PASS**: 5 synthetic-DOM UI event assertions: production bulk-control markup, 75% and 100% click bindings, arrival CTA presence, completion button click credits career.
- **NOT EXECUTED**: full browser E2E in native Windows/Android with visual screenshot inspection, real file download/import, and cross-device persistence. These require a live browser test and must not be treated as passed.
