# Local-only product decision — 2026-11-26

Owner approved personal offline game; downloadable ZIP, extract then open HTML locally. No server, database, accounts, cloud saves, mandatory connectivity, telemetry, hosted game deployment or public-release task. Public repository documentation remains separate; CI candidate archives are development evidence. All runtime data and saves stay on the device. Browser localStorage is profile/path-dependent and can be cleared; game is not hardware-locked. Portable user-controlled JSON export/import is required for backups and migration across folders/versions. Browser cannot silently overwrite arbitrary files on disk. Do not introduce DRM or machine fingerprinting. Support local PC first; Android optional device gate. Offline progression remains optional later design, never mandatory. Existing five environmental systems are still abstract simulation, not scientific prediction.

## MOLA build-time source
Official maintained PDS4 MEG004 directory: https://pds-geosciences.wustl.edu/missions/mgs/megdr.html. Product megt90n000cb.img and matching XML. 4 pixels/degree, global, 1440×720, elevation relative to areoid. PDS4 collection version 1.0: https://pds.nasa.gov/ds-view/pds/viewCollection.jsp?identifier=urn%3Anasa%3Apds%3Amgs_mola_topography_derived%3Adata_meg004 . Build script validates actual label, units, array shape, endian, data length, ranges, orientation; area-weighted 4×4 aggregation yields 360×180 int16 metres. Embedded base64 grid, bilinear longitude wrapping, latitude clamp. No runtime fetch. Sea level is a fictional configurable proxy, not water-volume conservation. Source/label/derived SHA-256 and source credit included in package. Local DNS blocked source acquisition; actual ingestion only verified if dedicated CI job succeeds. Fail closed on mismatched label/data; never pretend procedural terrain is measured.
