## Reference game
TerraGenesis — Space Settlers, created by Alexander Winn / Edgeworks Entertainment, published by Tilting Point. Classic era 2016–2018; later PC versions and expansions are additional research leads. Prior research reports iOS 2016, Android 2018 and PC 2020; exact dates, Unity implementation and acquisition history require primary-source confirmation before being treated as authoritative. The precise version remembered by the owner is not established. No official open-source game code was identified in the earlier research; absence is not proof none exists. Do not decompile, redistribute proprietary code or reuse protected branding/assets.
