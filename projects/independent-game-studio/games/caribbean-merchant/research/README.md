# Original-mechanics research and design provenance

The nostalgic source was **Port Royale 2 Mobile (Elkware, Java mid-2000s)**. Documentation for the PC version **Port Royale 2 (Ascaron, 2004)** is richer, but the two are not interchangeable.

| Source type | Supports | Caveat |
|---|---|---|
| [Ascaron PC manual](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/12470/manuals/pr2_manual_english.pdf) | Warehouses, manager price/reserve rules, governors, city buildings, pirate bases, competitor traders | **PC edition only**, not proof for mobile mechanics |
| [Pocket Gamer mobile review (2005)](https://www.pocketgamer.com/port-royale-2/review/) | Mobile port trade, governors, navigation, battles | Secondary review |
| [Archived Java game description](https://java2phone.ru/eng/383) | 8 goods, 12 ship types and a mobile manager auto-sale description | Archive/translation may have encoding gaps |
| [NOAA ETOPO relief data](https://www.ncei.noaa.gov/products/etopo-global-relief-model) | Geography and ocean bathymetry in game map | Geography source, not original game's map |
| [Basemap documentation](https://matplotlib.org/basemap/stable/api/basemap_api.html) | Processing/provenance for local relief imagery | A visualization dependency used during preparation |

## Adaptation vs invention

**Original-inspired:** trade/managers, governors, ships and ammo, pirate hideouts, tactical battles, warehouses, competing merchants.  
**Player-requested convenience features:** one actively managed vessel, ten different factories in *every* city, percentage-based autosale, clear combat odds, atomic contract loading, extensive modern achievements.

Neither original code/assets nor any game JAR were reverse engineered for this project. Mechanic names do not imply official affiliation.
