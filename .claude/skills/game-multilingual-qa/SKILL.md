# game-multilingual-qa

Version: 1.0.0 (2026-11-25).

Inventory all user-visible strings: headings, buttons, presets/time controls, selects, dialogs, tooltips, aria labels, notifications, errors, game events, promotion/color/options, status, online states, help, onboarding and settings. Centralize translation keys; check coverage and unintended fallback per locale including interpolation, plurals, numbers and terminology. Verify new/changed keys and affected UI; reuse unchanged evidence. Missing key, wrong-language fallback or semantic defect is FAIL for affected locale/gate; static key coverage does not prove real browser flow.
